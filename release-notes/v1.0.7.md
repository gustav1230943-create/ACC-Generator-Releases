## ACC Generator v1.0.7

**New: Multitool layout** — switch in *Settings → Design & Fenster → Oberfläche*:

- Sidebar with Generator, Email, Stats, 2FA codes, Notes, Encoder / Hash, Time zones, Units, Random, Shortcuts
- **Label & tags** for every generated account
- **Random / Passphrase** mode (e.g. `GlacierRavenPixelComet47`, Steam-compatible)
- **Bulk generate** up to 100 accounts at once and **Copy all as CSV**
- History with search, sorting, tag filter, ★ favorites and edit
- **Mini mode** — small always-on-top window with copy buttons and Generate

**Designs & window**

- 7 color designs: Original, Fluent, ImGui, NiceGUI, Material, Terminal, Multitool
- **Window transparency** 0–100 % (Ctrl+0 resets to 0 %)

**License**

- This version requires a **license key** on first start
- The license is checked live: if a key is paused, blocked or expires, the app locks immediately; if it is blocked, banned or deleted you are signed out
